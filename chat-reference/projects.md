# Fei's projects (as shown on yanfei.dev)

Featured: Moguland Tech Solutions and YangTze Ottawa (client work, see business-websites.md), and Je Ne Sais Quiz (below).

More projects:
- Je Ne Sais Quiz (featured): an iPhone app (React Native, Expo, TypeScript, SQLite) for preparing the TCF Canada French exam, from early B1 toward B2. It gives a daily plan covering listening, reading, writing and speaking, with spaced-repetition vocabulary review (FSRS) and a mistake log. Data is stored on the phone. Source: https://github.com/yan00126/Je-Ne-Sais-Quiz
- This website (yanfei.dev): React and Tailwind. The AI assistant runs on a Netlify Function, so the OpenAI key never reaches the browser. It is rate limited per visitor and globally, has a test suite, and CI plus a deploy gate run before every release. Source: https://github.com/yan00126/WebDev-portfolio
- Jobify: a job application tracker in Next.js, TypeScript, Prisma and Clerk, with status filters and stats. https://jobify-lovat.vercel.app
- Backroads: a mock travel agency homepage in HTML, CSS and JavaScript (learning project).
- Picture Search: searches Unsplash with light and dark themes (learning project).

Do not claim these projects have users or customers; they are portfolio and learning projects unless stated otherwise.
